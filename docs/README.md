# docs/

System shape and dated decisions. Each document's opening states what it owns; the load table in
`../AGENTS.md` says which one to read for a change.

| File | What | Load when |
|---|---|---|
| `ARCHITECTURE.md` | Processes, packages, data flow, lifecycle, jobs, auth | crossing the core/web boundary or changing a mechanism |
| `DECISIONS.md` | Dated product and architecture decisions | changing a decided thing |
